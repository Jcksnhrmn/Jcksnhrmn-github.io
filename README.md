# What Should I Drink?

A small Next.js web app that helps you decide what to make based on the alcohol, mixers, and fruit you already have at home.

The app also includes a **Drunk Mode** UI with bigger buttons and simpler prompts to make it easier to use if someone has already been drinking.

> Disclaimer: This app is for educational purposes only. Please drink responsibly and only if you are of legal drinking age.

---

## Features

- Select which **alcohol(s)**, **mixers**, and **fruit/garnish** you have.
- Click **"What can I make?"** to generate a drink idea.
- Shows:
  - Drink name
  - Description
  - Ingredients list
  - Step-by-step instructions
  - Simple drink image (placeholder)
- 👍 / 👎 feedback buttons that track likes and dislikes for this session.
- **Drunk Mode**:
  - Toggle at the top of the page.
  - Larger fonts and a “BIG GREEN BUTTON” label for the main action.
  - Designed to simplify the UI if someone is impaired.

---

## How It Works (Concept)

Right now, the drink is generated by a local function in `pages/index.js` called `generateDrinkSuggestion`. It looks at the selected ingredients and picks a matching drink pattern (e.g., vodka + orange juice → screwdriver-style drink).

In a future version, this is where we would call the **OpenAI / ChatGPT API** with the user’s ingredients and ask it to generate a custom cocktail or mocktail recipe.
